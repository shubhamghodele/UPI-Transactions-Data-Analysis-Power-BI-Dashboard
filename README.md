UPI Transactions Data Analysis – Power BI Dashboard

1.Project Title / Headline

💳 UPI Transactions Power BI Dashboard: Monthly Transaction & Balance Insights
A dynamic and interactive Power BI dashboard designed to analyze UPI transaction trends, transaction amounts, remaining balances, and user behavior across banks, cities, devices, and demographics.

2.Short Description / Purpose

The UPI Transactions Analytics Dashboard is a comprehensive Power BI report built to explore and monitor digital payment behavior through UPI transactions. The dashboard provides insights into monthly transaction amounts, remaining balances, transaction types, payment methods, and customer demographics.
It is designed for data analysts, fintech professionals, banking teams, and business decision-makers who want to understand UPI usage patterns and financial trends.

3.Tech Stack

The dashboard was built using the following tools and technologies:
• 📊 Power BI Desktop – Primary tool for dashboard design and interactive visualizations
• 📂 Power Query – Data cleaning, transformation, and preparation
• 🧠 DAX (Data Analysis Expressions) – Used for calculated measures, KPIs, and dynamic charts
• 📝 Data Modeling – Single fact table with calculated columns and measures for analysis
• 📁 File Formats – .pbix for development and .png for dashboard previews

4.Data Source

The dataset contains structured UPI transaction records, including:
• Transaction Details – Transaction type, payment method, purpose
• Financial Metrics – Transaction amount, remaining balance, currency
• Time Attributes – Month and year of transaction
• Bank Information – Bank name (sent & received)
• Customer Demographics – Age group, gender
• Location & Device – City, device type
This dataset is used to analyze UPI transaction behavior, balance trends, and user segmentation.

5.Features / Highlights

 Business Problem:
With the rapid growth of UPI payments, organizations face challenges in answering questions such as:
• How do transaction amounts vary month-wise?
• Which months show peak transaction activity?
• How does remaining balance fluctuate over time?
• How do transactions differ by city, bank, device, and customer demographics?

Analyzing raw transaction data without visualization is inefficient and time-consuming.

Goal of the Dashboard:
The goal of this dashboard is to provide an interactive financial analysis tool that:
• Tracks monthly UPI transaction trends
• Compares transaction amounts and remaining balances
• Enables drill-down by bank, city, device, and customer profile
• Supports data-driven insights for digital payment analysis


Bookmarks:
The dashboard uses bookmarks to switch between different views easily without changing filters.

• Transactions by Month – Line Chart
Shows monthly UPI transaction trends using a line chart. Helps understand increase or decrease in transactions over time.

• Transactions by Month – Column Chart
Displays monthly UPI transaction amounts using columns. Makes it easy to compare transaction values between months.

• Balance by Month – Line Chart
Shows how the remaining balance changes month by month using a line chart.

• Balance by Month – Column Chart
Compares remaining balance for each month using a column chart.

City & Currency Matrix Table:

Breaks down transaction amount and remaining balance by city, currency, and month.

Interactive Filters (Slicers):

Includes slicers for:
• Bank Name (Sent & Received)
• City
• Device Type
• Gender
• Age Group
• Merchant Name
• Payment Method
• Transaction Type
• Purpose
These enable detailed drill-down and customized analysis.

Business Impact & Insights:
• Transaction Trend Analysis – Identifies high-activity months and seasonal trends
• Balance Monitoring – Tracks how remaining balances change over time
• User Behavior Insights – Understands transaction patterns by age, gender, and device
• Geographical Analysis – Compares UPI usage across cities
• Decision Support – Helps fintech and banking teams improve digital payment strategies
